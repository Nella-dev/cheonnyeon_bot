# 🌑 천년 길드 디스코드 봇
**이클립스: 더어웨이크닝** · 길드명 **천년**

공지사항 · 길드 투표 · 분배 · 길드 관리 · 길드원 목록을 한 번에 관리하는 슬래시 명령어 봇입니다.

---

## ⚠️ 먼저 꼭 읽어주세요

제가 대신 만들어 드린 것은 **봇 프로그램(코드) 전체**입니다.
아래 두 가지는 디스코드 계정 주인이 아니면 대신 할 수 없어서, **휴대폰으로 5분이면 직접 하실 수 있게** 순서를 적어두었습니다.

1. **봇 토큰 발급** — 디스코드 개발자 포털에서 직접 (휴대폰 가능 ✅)
2. **서버에 봇 초대** — 초대 링크 클릭 한 번 (휴대폰 가능 ✅)

그리고 봇이 24시간 켜져 있으려면 **컴퓨터 없이 돌아가는 서버(호스팅)** 가 필요합니다. 3단계에 무료 방법을 정리했습니다.

> 정리: **코드는 100% 완성되어 있습니다.** 토큰 발급 → 초대 → 호스팅 3단계만 하시면 바로 작동합니다.

## 📱 휴대폰으로 하는 3단계 설치

### 1단계. 봇 만들고 토큰 받기 (약 3분)

1. 휴대폰 브라우저에서 **https://discord.com/developers/applications** 접속 후 로그인
2. 오른쪽 위 **`New Application`** → 이름에 `천년 봇` 입력 → 체크 후 **Create**
3. 왼쪽 메뉴 **`Bot`** 클릭
4. **`Reset Token`** → **`Yes, do it!`** → 화면에 나오는 긴 문자열을 **복사**
   - 이 값이 `.env` 파일의 `DISCORD_TOKEN` 입니다.
   - ⚠️ 이 토큰은 비밀번호와 같습니다. 아무에게도 보여주지 마세요. (노출되면 `Reset Token`으로 재발급)
5. 같은 `Bot` 화면을 아래로 내려 **`Privileged Gateway Intents`** 3개를 모두 **ON**
   - `Presence Intent`
   - **`Server Members Intent`** ← 길드원 목록 기능에 **필수**
   - `Message Content Intent`
   - 각 항목의 `Save Changes` 버튼을 눌러 저장

### 2단계. 서버에 봇 초대하기 (약 1분)

1. 왼쪽 메뉴 **`OAuth2`** → **`URL Generator`**
2. **Scopes** 에서 `bot` 과 `applications.commands` **둘 다 체크**
3. 아래 **Bot Permissions** 에서 다음을 체크

   | 권한 | 왜 필요한가요 |
   |---|---|
   | View Channels | 채널 보기 |
   | Send Messages | 공지·투표·분배 글 올리기 |
   | Embed Links | 임베드 카드 사용 |
   | Read Message History | 공지 목록 읽기 |
   | Manage Channels | `/서버세팅` 으로 채널 자동 생성 |
   | Manage Roles | `/직책변경` 시 서버 역할 지급 |
   | Kick Members | `/길드추방` |
   | Manage Messages | 투표 버튼 관리 |

4. 화면 맨 아래 **Generated URL** 을 복사 → 브라우저 주소창에 붙여넣기
5. **`천년` 서버 선택** → **승인** → 서버에 봇이 들어옵니다 ✅
6. 디스코드에서 서버 **서버 ID** 도 복사해 두세요 (설정 → 고급 → 개발자 모드 ON → 서버 아이콘 길게 눌러 `서버 ID 복사`)

### 3단계. 봇 켜두기 (호스팅)

봇은 내 휴대폰이 아니라 **24시간 켜져 있는 곳**에서 돌아가야 합니다. 아래 중 하나를 고르세요.

#### ⭐ 추천 A. Railway (가장 쉽고 무료로 시작 가능)
1. 휴대폰 브라우저로 **https://railway.app** → GitHub 계정으로 가입
2. `New Project` → **`Deploy from GitHub repo`** (먼저 이 zip 파일을 GitHub에 올려두면 됩니다)
3. 프로젝트 → **`Variables`** 탭에서 아래 두 개 추가
   - `DISCORD_TOKEN` = 1단계에서 복사한 토큰
   - `GUILD_ID` = 2단계에서 복사한 서버 ID
4. `Settings` → **`Start Command`** 에 `python bot.py` 입력
5. 자동으로 실행되고, 로그에 `로그인 완료` 가 뜨면 성공 🎉

#### 추천 B. Render
1. **https://render.com** 가입 → `New` → **`Background Worker`**
2. GitHub 저장소 연결
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Environment 에 `DISCORD_TOKEN`, `GUILD_ID` 추가
   - 무료 플랜은 일정 시간 후 잠들 수 있어, 상시 운영은 유료(월 $7 정도)가 안정적입니다.

#### 추천 C. 집 PC (나중에 퇴근하고 PC 쓸 때)
1. **https://www.python.org/downloads/** 에서 Python 3.10 이상 설치 (설치 시 `Add Python to PATH` **반드시 체크**)
2. 이 zip 파일 압축 풀기 → 폴더에서 주소창에 `cmd` 입력 후 Enter
3. 아래 명령어 순서대로 입력

```bat
pip install -r requirements.txt
copy .env.example .env
notepad .env
```
4. 메모장이 열리면 `DISCORD_TOKEN=` 뒤에 토큰, `GUILD_ID=` 뒤에 서버 ID 입력 → 저장
5. 아래 명령어로 점검 후 실행

```bat
python check.py
python bot.py
```
6. `로그인 완료` 메시지가 보이면 성공. 이 창을 닫으면 봇이 꺼집니다.

## 🚀 설치 후 첫 설정 (디스코드에서)

서버에서 아래 명령어를 순서대로 입력하세요.

1. **`/서버세팅`** — 천년 길드용 카테고리 3개와 채널 7개가 자동 생성됩니다. (운영진 역할도 함께 지정 가능)
2. **`/채널설정`** — 채널이 자동으로 잡혔는지 확인
3. **`/길드원등록`** — 길드원 정보 등록 시작
4. **`/도움말`** — 전체 명령어 확인

> 슬래시 명령어가 안 보이면: 디스코드를 완전히 껐다 켜거나, `.env` 의 `GUILD_ID` 를 채우고 봇을 재시작하면 즉시 등록됩니다. (`GUILD_ID` 없이 실행하면 전역 등록이라 최대 1시간 걸립니다)

## 📁 파일 구조

```
eclipse-bot/
├── bot.py              # 실행 진입점 (명령어 등록·오류 처리)
├── config.py           # 길드명·색상·채널 이름 설정
├── database.py         # SQLite 저장소 (길드원·투표·분배·경고·포인트)
├── utils.py            # 임베드·권한·채널 탐색·페이지네이션
├── check.py            # 실행 전 점검 스크립트
├── cogs/
│   ├── setup.py        # /서버세팅, /채널설정, /운영진역할, /도움말
│   ├── announcement.py # /공지, /공지목록
│   ├── vote.py         # /투표만들기, /투표결과, /투표목록, /투표종료
│   ├── distribution.py # /분배시작, /입찰, /주사위, /분배현황, /분배완료 ...
│   ├── management.py   # /길드원등록, /경고, /길드추방, /포인트 ...
│   └── roster.py       # /길드원목록, /길드원검색, /길드현황, /출석
├── requirements.txt
└── .env.example
```

데이터는 `data/eclipse.db` (SQLite) 에 저장됩니다. **이 파일만 백업하면 모든 기록이 보존됩니다.**

## 🔧 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 슬래시 명령어가 안 보임 | `.env` 의 `GUILD_ID` 입력 후 봇 재시작 (즉시 등록) |
| 봇이 오프라인 | 호스팅 서비스 로그 확인 / 토큰 오타 확인 |
| `권한이 부족합니다` | 봇 역할을 대상 역할보다 **위로** 올리기 |
| 채널을 못 찾음 | `/채널설정` 으로 직접 지정 |
| 멤버 목록이 비어 있음 | 개발자 포털에서 `Server Members Intent` ON 확인 |

## 🎨 커스터마이징

`config.py` 파일만 고치면 됩니다.

```python
GAME_NAME = "이클립스: 더어웨이크닝"   # 게임 이름
GUILD_NAME = "천년"                    # 길드 이름
COLOR_MAIN = 0x7B5CFF                  # 테마 색상 (보라)
DEFAULT_RANKS = ["길드마스터", ...]     # 직책 목록
DEFAULT_JOBS = ["나이트블레이드", ...]  # 직업 자동완성 후보
```
